# S-016 — Function calling

- Publisher: OpenAI API Documentation.
- URL: https://developers.openai.com/api/docs/guides/function-calling
- Accessed: 2026-10-18.
- Evidence type: first-party technical documentation.

Function calling lets an application describe functions to a model, receive a
structured request, execute the requested function in application code, and
send the tool result back to the model. The model does not itself perform the
application-side action. This supports the architecture recommendation that
LifePilot validate a proposed task and write it to its own store rather than
delegating write authority to the model or provider.
