# S-017 — Your data

- Publisher: OpenAI API Documentation.
- URL: https://developers.openai.com/api/docs/guides/your-data
- Accessed: 2026-10-18.
- Evidence type: first-party data-control documentation.

The API endpoint table states that API data are not used for training by
default. It lists up to 30 days of abuse-monitoring retention for the
Responses and Chat Completions endpoints. Zero Data Retention and modified
monitoring are separate eligibility/approval options, and endpoint or feature
limitations apply. Stateful endpoints and tools may retain application data
until deleted; privacy analysis must cover the chosen endpoint and tools, not
just the model.

These statements describe the provider's current documentation and are not
legal advice or a promise of zero retention for a typical API account.
