# S-009 — Multi-agent / LangChain Documentation

- Original URL: https://docs.langchain.com/oss/python/langchain/multi-agent
- Accessed: 2026-10-18
- Locator: Why multi-agent; patterns; choosing a pattern.
- Verification: official documentation page opened by coordinator.
- Publication/update date: not stated in retrieved page.
- Summary: LangChain describes multi-agent patterns including subagents,
  handoffs, skills, routers, and custom workflows. It says not every complex
  task needs a multi-agent design; a single agent with appropriate tools and
  prompt may suffice. It identifies specialization, context management, and
  parallelization as reasons to consider multi-agent patterns.
- Supports: separate model routing from ordinary tool calls and avoid
  unnecessary multi-agent complexity.
- Caveats: conceptual patterns do not prescribe which LifePilot workflows
  should use them.
