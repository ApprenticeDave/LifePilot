# S-026 — Gemini API billing

- Publisher: Google AI for Developers.
- URL: https://ai.google.dev/gemini-api/docs/billing
- Accessed: 2026-10-18.
- Evidence type: first-party billing documentation.

The guide explains that new accounts start on the Free Tier and that linking
an active billing account moves usage to Paid Tiers, which provide higher
limits and ensure prompts/responses are not used to improve Google's products
under the referenced terms. It describes billing setup and prepaid or
postpaid options; exact eligibility and minimums can change.

No account was created and no billing was enabled for this research.
