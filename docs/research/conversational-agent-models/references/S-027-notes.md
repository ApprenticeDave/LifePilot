# S-027 — Cloud models

- Publisher: Ollama Blog.
- URL: https://ollama.com/blog/cloud-models
- Accessed: 2026-10-18.
- Evidence type: first-party product announcement.

Ollama describes cloud models as a way to run larger models on datacenter
hardware through the existing Ollama experience and OpenAI-compatible API.
Cloud models require signing in to ollama.com. The page's listed models and
preview status can change.

The blog says cloud prompts are not retained. The separate Ollama Privacy
Policy (S-029) gives details on transient processing. No model-quality,
pricing comparison, or local-machine latency was established here.

No model was run and no prompt was sent to Ollama Cloud.
