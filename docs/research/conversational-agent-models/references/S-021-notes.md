- Publisher: Anthropic Claude Platform Documentation.
- URL: https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview
- Accessed: 2026-10-18.
- Evidence type: first-party technical documentation.

The tool-use guide distinguishes client tools defined by the application from
server tools run by Anthropic. For a client tool, the model returns a
structured request and application code executes it. Provider-run tools are a
separate data path. This supports keeping LifePilot's task writes local and
reviewing external tool behavior independently.
