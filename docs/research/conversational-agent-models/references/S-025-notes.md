# S-025 — Gemini API Terms of Service

- Publisher: Google AI for Developers.
- URL: https://ai.google.dev/gemini-api/terms
- Accessed: 2026-10-18.
- Evidence type: first-party service terms.

The terms state that for paid services Google does not use prompts/responses
to improve products, but logs them for a limited period for safety, security,
and legal/regulatory purposes; data may be transiently stored or cached in
countries where Google or agents operate. The terms state that free-service
content may be used to improve products, including human review. They also
state that API clients in the EEA, UK, or Switzerland must use paid services.

These terms can change and have account/region implications. Verify the exact
billing tier, contract, and current data terms before use. This note is not
legal advice.
