# S-022 — API and data retention

- Publisher: Anthropic Claude Platform Documentation.
- URL: https://platform.claude.com/docs/en/manage-claude/api-and-data-retention
- Accessed: 2026-10-18.
- Evidence type: first-party API data-retention documentation.

Anthropic documents Zero Data Retention (ZDR) as an organization-level arrangement that must be requested and enabled; it is not
the default promise for every API account. Eligibility varies by endpoint
feature. The page says Claude Fable 5.1, Claude Mythos 5.1, Claude Fable 5, and
Claude Mythos 5 require 30-day retention unless Anthropic expressly authorizes
otherwise. Claude Sonnet 5.5 is not included in this specific listed
covered-model exception. Retained data are not used for model training without
express permission. Third-party integrations have separate data handling.

This policy is mutable and account/feature specific. Recheck the current
contract and feature table before sending sensitive information; this note is
not legal advice.
