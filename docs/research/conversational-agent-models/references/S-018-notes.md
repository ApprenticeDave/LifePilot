# S-018 — Pricing

- Publisher: OpenAI API Documentation.
- URL: https://developers.openai.com/api/docs/pricing
- Accessed: 2026-10-18.
- Evidence type: first-party pricing page.

The pricing page is mutable and publishes per-model, per-token rates and
separate charges for some tools. At access time, GPT-6.1 Sol standard short-
context pricing was USD $2 per million input tokens and $10 per million output
tokens; long-context rates were higher. Prices are not durable estimates;
verify current rates and model availability before any evaluation or account
configuration. Usage-based API access can incur charges.

No API was called and no charge was incurred for this research.
