# S-015 — Using GPT-6

- Publisher: OpenAI API Documentation.
- URL: https://developers.openai.com/api/docs/guides/latest-model
- Accessed: 2026-10-18.
- Evidence type: first-party model selection and capability descriptions.

The guide presents GPT-6 Astra as its highest-intelligence option for demanding
reasoning and professional work, GPT-6.1 Sol as balancing speed, cost, and
intelligence, and GPT-6 Luna as its fastest, most cost-effective option for
focused high-volume tasks. It recommends choosing based on task needs and
evaluating cost/speed/quality. These are the vendor's descriptions, not
independent comparative results for LifePilot's conversational style.

The GPT-6 guide says tool calling uses the Responses API and the application
still runs tools and manages pending work. API model identifiers and product
details may change; recheck before implementation.
