# S-028 — Cloud

- Publisher: Ollama Documentation.
- URL: https://docs.ollama.com/cloud
- Accessed: 2026-10-18.
- Evidence type: first-party API and account documentation.

Ollama documents cloud model requests through `https://ollama.com/api/chat`
using an API key, or through a signed-in local Ollama server. Its docs say
cloud models need not be downloaded and list current models through its API.
The cloud endpoint can also be used by supported OpenAI- or
Anthropic-compatible clients. Cloud usage, model retirement, and pricing are
mutable; the documentation directs users to account usage and plans.

The page says cloud prompts/responses are processed to answer requests and
are not used for training. See S-029 for the provider policy details.

No account was created, key generated, or request made.
