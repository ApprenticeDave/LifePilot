# S-019 — Choosing the right Claude model

- Publisher: Anthropic Claude Platform Documentation.
- URL: https://platform.claude.com/docs/en/about-claude/models/choosing-a-model
- Accessed: 2026-10-18.
- Evidence type: first-party model-selection guide.

Anthropic recommends selecting based on capability, speed, cost, and effort,
and testing models on the actual workload. The page presents an
efficiency-first path (start with a smaller/faster model and upgrade only for
measured gaps) and a capability-first path for complex work. Its characterizations
are vendor claims, not independent evidence about friendly assistant behavior.
