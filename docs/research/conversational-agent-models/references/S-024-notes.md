# S-024 — Gemini Developer API pricing

- Publisher: Google AI for Developers.
- URL: https://ai.google.dev/gemini-api/docs/pricing
- Accessed: 2026-10-18.
- Evidence type: first-party pricing and data-use labels.

The pricing table distinguishes free and paid tiers and lists whether data
are used to improve products. The retrieved page marks paid-tier content "No"
and free-tier content "Yes" for the shown Gemini model rows; rates vary by
model, tier, token type, and effective date. Verify the chosen model's current
rate and terms on the official page before use.
