# S-023 — Gemini API models

- Publisher: Google AI for Developers.
- URL: https://ai.google.dev/gemini-api/docs/models
- Accessed: 2026-10-18.
- Evidence type: first-party model catalogue.

The model catalogue lists Gemini API model IDs and Google's task-focused
descriptions, including reasoning, low-latency/high-volume, and audio
conversational use cases. Model availability and descriptions are mutable.
This report treats Gemini as a provider worth testing, not as a verified
winner for LifePilot dialogue quality.

No content was submitted to Google.
