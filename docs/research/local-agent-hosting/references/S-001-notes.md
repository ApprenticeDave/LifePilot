# S-001 — Windows / Ollama

- Original URL: https://docs.ollama.com/windows
- Accessed: 2026-10-18
- Locator: Windows support; system requirements; filesystem requirements;
  API access; standalone CLI.
- Verification: official documentation page opened.
- Publication/update date: not stated in retrieved page.
- Summary: Ollama documents a native Windows app supporting NVIDIA and AMD
  GPUs, a local API at `http://localhost:11434`, Windows 10 22H2 or newer,
  NVIDIA driver 551.61 or newer, and a per-user installation that does not
  require Administrator by default. Model storage can be redirected using
  `OLLAMA_MODELS`.
- Supports: Windows setup suitability and local API availability.
- Caveats: the page does not establish actual performance or VRAM usable by
  this particular vGPU. Model downloads require storage and network access.

  permission was not assessed.
