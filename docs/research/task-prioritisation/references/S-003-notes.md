# S-003 notes: W3C COGA design guide

Source: W3C WAI, "Making Content Usable for People with Cognitive and Learning Disabilities"
Original URL: https://www.w3.org/TR/coga-usable/

## Summary
The guide states that users with cognitive and learning disabilities may struggle with orientation, remembering new patterns, and understanding how to use controls. It recommends familiar design patterns, clear purpose, and simple user decisions.

## Relevance to LifePilot
This directly supports keeping task interactions simple and explicit. A manually chosen important flag, clear labels, and visible hierarchy are better than hidden rankings or difficult decision matrices.

## Caveats
This is accessibility guidance, not a productivity trial. It is about reducing barriers and supporting comprehension, not proving one productivity model is objectively best.
