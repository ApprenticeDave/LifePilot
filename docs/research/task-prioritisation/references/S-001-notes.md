# S-001 notes: Eisenhower Matrix

Source: MindTools, "Eisenhower Matrix".
Original URL: https://www.mindtools.com/a4mi7n0/eisenhower-matrix

## Summary
The page describes the classic framework in which actions are sorted by urgency and importance. It is a practical decision aid rather than a system for automatically ranking all tasks.

## Relevance to LifePilot
The key value is the distinction between urgent and important, which fits a task list that should not force a user into a single ranking model. It suggests that a user can decide whether a task deserves attention without a hidden score.

## Caveats
This is a productivity tool explanation rather than a research paper. It does not prove that one matrix is the best possible strategy for all people or all task types.
