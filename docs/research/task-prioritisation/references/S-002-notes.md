# S-002 notes: What is GTD?

Source: Getting Things Done, "What is GTD?"
Original URL: https://gettingthingsdone.com/what-is-gtd/

## Summary
The GTD overview explains a method that organizes tasks by clarifying what they are, deciding the next action, and reducing mental load by capturing work outside the head. It frames task management as explicit action rather than abstract priority scoring.

## Relevance to LifePilot
This suggests the app should help users define the task simply and then decide what to do next without overcomplicating the interface. A lightweight, manual choice is consistent with the GTD idea that the goal is clarity and manageable next steps.

## Caveats
This is a methodology description, not a comparative experiment. It offers a strong conceptual match but not a proof that all users need a full GTD model.
