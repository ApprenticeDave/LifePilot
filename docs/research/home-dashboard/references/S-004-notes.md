# S-004: Reflow

URL: https://www.w3.org/WAI/WCAG22/Understanding/reflow.html

Publisher: W3C WAI. Access: 2026-10-18 research session.
Locator: SC 1.4.10, Intent.

Original summary: ordinary vertically scrolling content must preserve
information and functionality at a width equivalent to 320 CSS pixels without
two-dimensional scrolling, subject to exceptions for content whose meaning
requires two dimensions.
Supports F-04 and a mobile single-column dashboard.

Caveat: this is an explanatory page reproducing the criterion. Testing only
page overflow is insufficient to establish full conformance or internal layout.
