# S-006: Use of color

URL: https://www.w3.org/WAI/WCAG21/Understanding/use-of-color.html

Publisher: W3C WAI. Access: 2026-10-18 research session.
Locator: SC 1.4.1 and Intent.

Original summary: color must not be the sole visual means of identifying
information, an action or status. Text and other visual distinctions can convey
the same meaning.
Supports F-06 and explicitly labeled life-area cards.

Caveat: color is not prohibited. Contrast, programmatic labels and other
accessibility requirements must be assessed separately.
