# S-005: Target size

URL: https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html

Publisher: W3C WAI. Access: 2026-10-18 research session.
Locator: SC 2.5.8 explanation, Intent and Exceptions.

Original summary: targets generally need 24-by-24 CSS pixel size or the stated
spacing/other exceptions. The rationale is to reduce accidental activation.
The page recommends considering the stricter enhanced criterion for important
controls.
Supports F-05.

Caveat: do not claim every visible icon must itself be 24 pixels: the actionable
target may include its label and padding. This is not a complete accessibility
audit or evidence that very large visual checkboxes are beneficial.
