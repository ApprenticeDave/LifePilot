# S-001: Cognitive accessibility

URL: https://www.w3.org/TR/coga-usable/

Publisher: W3C WAI. Access: 2026-10-18 research session.
Locators: design guide 4.1; Objective 1.

Original summary: make the purpose of pages and controls apparent, use familiar
patterns and terms, and support orientation through clear headings and labels.
Supports F-01 and a predictable home hierarchy.

Caveat: supplemental guidance beyond WCAG, not a dashboard comparison trial.
The recommendation for visible icon labels is a design interpretation, not a
verbatim requirement from this excerpt.
