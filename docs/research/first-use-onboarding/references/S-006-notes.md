# S-006: Consistent Help

- Publisher: W3C WAI.
- URL: https://www.w3.org/WAI/WCAG22/Understanding/consistent-help.html
- Access: research session dated 2026-10-17; see [register](../sources.md) for date caveat.
- Locators: WCAG 2.2 SC 3.2.6 explanation, "Intent", "Limitations and Exceptions".
- Original summary: repeated help mechanisms should maintain relative order
  across a set of pages so users can find them predictably.
- Supports: F-06; consistent placement if setup offers repeated help.
- Caveats: it does not mandate creating a help channel, constant human
  availability or identical positioning under every user-initiated layout
  change. Inline field instructions are not the same as the help mechanisms discussed.
