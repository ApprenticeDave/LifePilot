# S-002: Cognitive and learning accessibility

- Publisher: W3C WAI.
- URL: https://www.w3.org/TR/coga-usable/
- Access: research session dated 2026-10-17; see [register](../sources.md) for date caveat.
- Locators: 4.1, 4.2.1 "Make the Purpose of Your Page Clear", 4.2.4 "Make Each Step Clear".
- Original summary: familiar controls and clear purpose help users orient
  themselves. Multi-step processes should make completed, current and remaining
  steps and important choices apparent, supporting reorientation after distraction.
- Supports: F-02; visible stages and predictable controls in setup.
- Caveats: supplemental guidance beyond normative WCAG; not universal evidence
  about every neurodivergent person. Scenarios explain rationale, not measured effects.
