# S-001: Structuring forms

- Publisher: GOV.UK / Government Digital Service.
- URL: https://www.gov.uk/service-manual/design/form-structure
- Access: research session dated 2026-10-17; see [register](../sources.md) for date caveat.
- Locators: "Know why you're asking every question"; "Design for the most common
  scenarios first"; "Start with one thing per page".
- Original summary: justify questions by the service need, intended use and
  relevant users; branch so people answer relevant questions. Start with a
  single question, decision or message per page, and use user research to decide
  when grouping is better.
- Supports: F-01 and F-03; a guided, purpose-limited setup is a plausible starting
  design, not a prescribed final screen count.
- Caveat: public-service guidance does not prove that every profile field must
  have its own screen or that this flow beats chat for the intended audience.
