# S-005: Redundant Entry

- Publisher: W3C WAI.
- URL: https://www.w3.org/WAI/WCAG22/Understanding/redundant-entry.html
- Access: research session dated 2026-10-17; see [register](../sources.md) for date caveat.
- Locators: WCAG 2.2 SC 3.3.7 text, "Intent", "Exceptions".
- Original summary: previously supplied information needed again within the
  same process should be populated or selectable, subject to essential,
  security and invalid-information exceptions.
- Supports: F-04; avoid making users recall and retype prior setup answers.
- Caveat: the explanation explicitly excludes a requirement to persist data
  between sessions. It neither defines this product's resume storage nor
  removes the need to protect temporarily retained information.

Original paraphrase note, not a source copy. No quotations reproduced.
